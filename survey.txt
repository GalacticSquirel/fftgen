# McDonald's Food for Thoughts – Survey Page Definitions
#
# This file describes every page of the survey in order.
# The automation script reads it to know what to expect on each page.
#
# Derived from the actual survey HTML (saved as survey_source.html).
#
# Page types:
#   none      – informational, no user input (just click Next)
#   text      – text input fields (survey code, price)
#   radio     – single-choice radio buttons (one or more groups per page)
#   checkbox  – multi-select checkboxes (select all that apply)
#   textarea  – free-text comment box
#
# Rating scale used on satisfaction pages (5-point, HIGH = 5):
#   5 = Highly Satisfied / Highly Likely
#   4 = Satisfied / Likely
#   3 = Neither Satisfied nor Dissatisfied
#   2 = Dissatisfied / Unlikely
#   1 = Highly Dissatisfied / Highly Unlikely
